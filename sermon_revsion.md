# Sermon Revision

## 1. Purpose

Sermon revision is the process of improving a sermon **without losing the biblical truth, theological purpose, pastoral intent, or natural voice that made the sermon worth preaching in the first place**.

Revision should not mean endlessly polishing sentences.

The agent should revise the sermon in descending order of importance:

```text
Faithfulness
→ Meaning
→ Theology
→ Purpose
→ Structure
→ Exposition
→ Application
→ Pastoral Integrity
→ Clarity
→ Rhetoric
→ Style
```

The agent should fix the highest-level problem first.

A polished sentence cannot rescue a broken argument.

---

# 2. Revision Principles

### 2.1 Preserve what works

Revision is not rewriting for its own sake.

The agent should identify strong elements before changing them.

### 2.2 Change the smallest thing that solves the problem

If one paragraph is weak, do not rewrite the entire sermon.

If the structure is fundamentally broken, however, localized edits are insufficient.

### 2.3 Meaning before wording

The agent should determine whether an idea is correct before determining whether it is elegantly phrased.

### 2.4 Preserve the preacher's voice

The agent should improve communication without turning the sermon into generic AI prose.

The sermon should still sound like the preacher.

### 2.5 Do not polish around a foundational problem

If evaluation identifies a critical biblical or theological problem, the agent must address that problem directly.

---

# 3. Revision Inputs

Revision should begin from the available evidence.

Inputs may include:

* Original sermon request
* Sermon-development state
* Primary biblical text
* Research
* Sermon outline
* Sermon manuscript
* Evaluation results
* User feedback
* Specific requested changes
* Intended audience
* Preaching context

The agent should not revise based solely on vague impressions when a more precise diagnosis is available.

---

# 4. Diagnose Before Revising

The agent should first determine **what kind of problem exists**.

Common categories:

```text
Biblical
Interpretive
Theological
Structural
Expository
Pastoral
Application
Clarity
Pacing
Rhetorical
Stylistic
Redundancy
Accuracy
```

The agent should identify the root problem rather than merely editing its symptoms.

Example:

> "The conclusion feels weak."

Possible root causes:

* The landing point was never established.
* The sermon introduced too many ideas.
* The central idea was unclear.
* The application was generic.
* The conclusion is merely repeating information rather than resolving the sermon.

The agent should fix the underlying issue rather than simply making the final paragraph more dramatic.

---

# 5. Revision Severity

Use the evaluation severity established in `sermon_evaluation.md`.

### CRITICAL

Requires substantive correction before the sermon is considered usable.

### MAJOR

Requires meaningful revision to a significant section or the sermon architecture.

### MODERATE

Should generally be revised but does not require rebuilding the sermon.

### MINOR

Localized refinement.

Revision effort should correspond to severity.

---

# 6. Revision Order

When multiple issues exist, revise in this order:

```text
1. Biblical faithfulness
2. Interpretive integrity
3. Theological coherence
4. Central idea
5. Sermon purpose
6. Structure
7. Exposition
8. Application
9. Gospel / redemptive context
10. Pastoral integrity
11. Clarity
12. Emotional integrity
13. Rhetoric
14. Style
```

Do not revise lower-priority dimensions while higher-priority problems remain unresolved.

---

# 7. Biblical Revision

If the sermon misrepresents Scripture, the agent should:

1. Identify the problematic claim.
2. Re-examine the passage.
3. Determine what the text actually supports.
4. Determine whether the sermon can be reframed.
5. Rewrite the affected material.
6. Re-evaluate downstream sections affected by the change.

A biblical correction may require changes elsewhere in the sermon.

For example:

```text
Interpretation changes
→ Central idea changes
→ Structure changes
→ Application changes
→ Conclusion changes
```

The agent must follow those dependencies.

---

# 8. Interpretive Revision

When an interpretation is too strong, revise the language to accurately represent the evidence.

Examples:

Overstated:

> "This verse clearly teaches that God will always..."

More appropriate:

> "In this context, Paul emphasizes that God..."

The agent should not weaken a claim merely to avoid confidence.

It should calibrate confidence to evidence.

---

# 9. Theological Revision

If a sermon contains theological inconsistency, determine whether the problem is:

* Explicit
* Implied
* Caused by poor wording
* Caused by missing qualification
* Caused by an application that contradicts the theology

Whenever possible, correct the underlying idea rather than merely adding disclaimers.

For example, if a sermon unintentionally communicates salvation by performance, simply adding:

> "Of course, salvation is by grace."

may not solve the problem.

The structure and application may need to change.

---

# 10. Central Idea Revision

If the central idea is weak, the agent should stop and rebuild from the biblical claim.

A useful sequence is:

```text
Primary Text
→ Biblical Claim
→ Theological Significance
→ Human Tension
→ Sermon Purpose
→ Central Idea
```

The agent should not attempt to preserve a weak central idea merely because the manuscript has already been written.

If the central idea changes substantially, downstream sermon sections should be re-evaluated.

---

# 11. Structural Revision

Structural revision should occur when:

* Points do not logically build
* Important material appears too early or too late
* The sermon has multiple competing ideas
* The conclusion introduces the real point for the first time
* A major tension is abandoned
* Sections are redundant
* Application is disconnected from exposition
* The sermon does not reach a meaningful destination

Structural revision may involve:

* Combining sections
* Removing sections
* Reordering sections
* Expanding an underdeveloped section
* Moving application
* Rebuilding transitions
* Rewriting the conclusion

The agent should not preserve an outline merely because it is familiar.

---

# 12. Expository Revision

If the sermon mentions Scripture without adequately explaining it, revise toward greater textual clarity.

Possible revisions:

* Add missing context
* Explain the relevant passage
* Clarify a key term
* Show how a conclusion follows
* Remove unsupported claims
* Reduce unrelated commentary
* Strengthen connections between verses and sermon claims

The goal is not to add more biblical quotations.

The goal is to make the biblical reasoning clearer.

---

# 13. Application Revision

When application is generic, the agent should trace it backward:

```text
Application
← Theological implication
← Biblical meaning
← Text
```

The revised application should be specific enough to matter while remaining faithful to the text.

Avoid applications that amount only to:

* Try harder
* Be nicer
* Have more faith
* Pray more
* Trust God

unless the sermon actually explains what those responses mean in this particular context.

Application should show what obedience, faith, repentance, hope, or worship looks like.

---

# 14. Gospel Revision

If the sermon lacks an appropriate gospel connection, determine whether the problem is:

* The text's place in redemptive history has been overlooked
* Grace has been displaced by performance
* Christ's work is relevant but unexplored
* The sermon has treated Christian obedience independently of the gospel

If a gospel connection is not naturally central to the passage, do not manufacture one.

The agent should seek a **meaningful connection rather than a mandatory formula**.

---

# 15. Pastoral Revision

Revise pastoral problems when the sermon:

* Speaks carelessly about suffering
* Assumes circumstances the audience may not share
* Creates unnecessary guilt
* Uses shame as motivation
* Offers simplistic answers
* Treats people as rhetorical examples
* Corrects without compassion
* Encourages without truth

Pastoral revision should preserve truth while improving the way that truth is carried.

---

# 16. Emotional Revision

If emotional material feels manipulative, the agent should ask:

> Is the emotion coming from the truth, or is the rhetoric manufacturing the emotion?

Possible revisions:

* Remove an unnecessary story
* Shorten emotional buildup
* Let the biblical text carry more weight
* Replace sentiment with explanation
* Allow silence or simplicity
* Remove exaggerated language

The goal is not to eliminate emotion.

The goal is to make emotion **earned**.

---

# 17. Clarity Revision

When a sermon is difficult to follow, revise:

* Sentence length
* Vocabulary
* Transitions
* Paragraph order
* Repetition
* Abstract language
* Undefined terminology
* Pronoun references
* Overloaded sentences

The agent should preserve theological precision while improving accessibility.

Do not simplify an idea until it becomes inaccurate.

---

# 18. Spoken-Language Revision

The final manuscript should be tested as spoken communication.

Revise sentences that:

* Are difficult to say naturally
* Contain too many clauses
* Depend on visual punctuation
* Require rereading
* Sound like academic prose
* Use repeated formal constructions
* Contain unnecessary qualifiers

Prefer language that can be understood by a listener in real time.

---

# 19. Pacing Revision

Pacing should vary according to importance.

Slow down for:

* Major theological claims
* Important Scripture
* Emotional turning points
* Difficult concepts
* The landing point

Move quickly through:

* Redundant explanation
* Minor background
* Supporting details
* Material the listener already understands

The agent should not attempt to make every section equally substantial.

---

# 20. Redundancy Revision

Repetition can strengthen a sermon, but repetition without development weakens it.

When two sections communicate the same idea, determine whether they:

* Reinforce the idea from different angles
* Develop the idea
* Apply the idea differently

If they do none of these, combine or remove them.

---

# 21. Illustration Revision

Illustrations should be revised when they:

* Distract from the text
* Are too long
* Require too much explanation
* Overwhelm the theological point
* Contain questionable facts
* Create emotion without serving the message
* Repeat another illustration's function

Prefer the simplest illustration that accomplishes the needed purpose.

---

# 22. Research Revision

Research should be revised when:

* A claim is inaccurate
* A source is weak
* A claim is stronger than the evidence
* Background information overwhelms the sermon
* An interesting fact has no meaningful function

Research should be removed when it no longer serves the sermon.

The agent should never retain research merely because effort was spent finding it.

---

# 23. Cutting Material

Cutting is a legitimate form of revision.

The agent should consider removing material when it is:

* Redundant
* Tangential
* Unsupported
* Unnecessary
* Distracting
* More interesting than useful
* Repeating an already-established point

When cutting material, preserve the sermon's logical chain.

Do not remove a section simply because it is long if that section performs an essential function.

---

# 24. Expanding Material

Expansion is appropriate when a listener would otherwise be unable to understand an important claim.

Expand when:

* A theological conclusion appears without explanation
* A key verse is assumed rather than explained
* An important transition is missing
* An application requires additional reasoning
* A difficult concept needs clarification
* The conclusion is not earned

Do not expand merely to increase sermon length.

---

# 25. Preserving Voice

Revision should preserve the preacher's natural voice.

The agent should avoid:

* Generic inspirational language
* Excessive rhetorical flourish
* Artificially dramatic phrasing
* Constant rhetorical questions
* Repetitive three-part constructions
* Unnecessary alliteration
* Overly polished "AI sermon" language
* Language inconsistent with the preacher's established style

The goal is:

> **Better version of this preacher's sermon.**

Not:

> **Different preacher's sermon.**

---

# 26. User-Directed Revision

When the user requests a specific change, the agent should honor the request unless it creates a conflict with:

* Scripture
* Theology
* Accuracy
* Pastoral integrity
* The sermon's central purpose

If the requested change creates such a conflict, the agent should explain the problem and propose a faithful alternative.

---

# 27. Revision Scope

Before revising, determine the appropriate scope.

### Local Revision

One sentence, paragraph, transition, illustration, or section.

### Section Revision

A substantial portion of the sermon needs restructuring.

### Structural Revision

The sermon's architecture needs to change.

### Full Revision

The manuscript is built on a flawed central idea or interpretation and must be substantially rebuilt.

The agent should choose the smallest scope that adequately solves the identified problem.

---

# 28. Dependency Awareness

Changes propagate.

The agent should inspect downstream material whenever an upstream component changes.

For example:

```text
Primary Text changes
→ Interpretation changes
→ Theology changes
→ Central Idea changes
→ Structure changes
→ Application changes
→ Conclusion changes
```

Similarly:

```text
Central Idea changes
→ Every major movement should be checked
→ Applications should be checked
→ Conclusion should be checked
```

The agent should not revise one section in isolation when that section's meaning depends on the rest of the sermon.

---

# 29. Revision Loop

The default revision cycle is:

```text
Evaluate
   ↓
Identify Highest-Priority Problem
   ↓
Diagnose Root Cause
   ↓
Revise
   ↓
Re-evaluate Affected Sections
   ↓
Repeat if Necessary
```

The agent should stop when additional changes produce diminishing returns or begin altering valid stylistic preferences without solving meaningful problems.

---

# 30. Revision Should Not Become Endless

A sermon does not need to be perfect.

Revision should stop when:

* No critical issues remain
* No major unresolved issues remain
* The central idea is clear
* The structure is coherent
* The text is faithfully represented
* Application is appropriate
* The sermon sounds natural
* The conclusion lands properly
* Remaining issues are primarily stylistic preferences

The goal is not infinite optimization.

The goal is readiness to preach.

---

# 31. Final Revision Pass

Before declaring the sermon final, perform a final pass specifically for:

### Scripture

Are all major claims defensible from Scripture?

### Theology

Does the sermon remain internally and doctrinally coherent?

### Structure

Does every major section serve the central idea?

### Application

Does every major application follow from the sermon?

### Gospel

Is the sermon appropriately situated within the Christian story?

### Pastoral Integrity

Does the sermon speak truthfully and compassionately?

### Clarity

Can the sermon be understood when heard once?

### Voice

Does it still sound like the preacher?

### Economy

Is there anything unnecessary?

### Landing

Does the sermon end where it was intended to go?

---

# 32. Revision Output

When returning a revised sermon, the agent should not silently make major conceptual changes.

If the revision materially changes:

* The interpretation
* Central idea
* Theology
* Structure
* Application
* Conclusion

the agent should briefly identify the change and why it was necessary.

Minor wording and stylistic improvements do not require explanation.

---

# 33. Core Rule

Revision should not ask:

> **How can we make this sermon sound better?**

It should ask:

> **What is preventing this sermon from being more faithful, clear, coherent, pastoral, and effective?**

Then fix that problem.

**Revise the sermon toward faithfulness and clarity—not toward artificial perfection.**
