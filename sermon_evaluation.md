# Sermon Evaluation

## 1. Purpose

Sermon evaluation exists to determine whether a sermon is **faithful, coherent, meaningful, and effective** before it is considered final.

Evaluation is not primarily a literary critique.

A sermon can be:

* Beautifully written but biblically weak
* Theologically correct but pastorally disconnected
* Biblically faithful but structurally confusing
* Emotionally powerful but manipulative
* Well researched but unnecessarily complicated
* Clear and compelling but built on a faulty interpretation

The evaluator must therefore assess the sermon as a whole.

The primary question is:

> **Does this sermon faithfully communicate what Scripture says and lead the listener toward an appropriate response?**

---

# 2. Evaluation Principles

### 2.1 Faithfulness before effectiveness

A sermon that "works" rhetorically but misrepresents Scripture is not successful.

### 2.2 Meaning before preference

Evaluation should distinguish genuine weaknesses from personal stylistic preferences.

### 2.3 Whole sermon before individual sentences

The agent should evaluate the sermon primarily as an argument and pastoral communication rather than nitpicking isolated phrases.

### 2.4 Specific criticism over vague criticism

The agent should identify:

* What is wrong
* Why it matters
* How serious it is
* What should change

"Make it stronger" is not useful evaluation.

### 2.5 Revision should be proportional

Not every imperfection requires restructuring the sermon.

The agent should distinguish between:

* Critical problems
* Significant weaknesses
* Minor improvements
* Optional refinements

---

# 3. Evaluation Order

The sermon should be evaluated in this order:

```text
Scriptural Faithfulness
        ↓
Interpretive Integrity
        ↓
Theological Coherence
        ↓
Central Idea
        ↓
Sermon Structure
        ↓
Exposition
        ↓
Application
        ↓
Gospel / Redemptive Context
        ↓
Pastoral Integrity
        ↓
Clarity
        ↓
Emotional Integrity
        ↓
Rhetorical Effectiveness
        ↓
Style / Polish
```

Lower-level improvements should never be used to conceal higher-level problems.

There is no value in improving a transition when the sermon's central theological claim is wrong.

---

# 4. Scriptural Faithfulness

The first evaluation question is:

> **Does the sermon faithfully represent Scripture?**

Evaluate:

* Whether the primary text actually supports the sermon's claims
* Whether verses are used in context
* Whether surrounding context changes the interpretation
* Whether claims are being attributed to Scripture that Scripture does not make
* Whether quotations are accurate
* Whether paraphrases preserve meaning
* Whether supporting passages genuinely support the claim
* Whether application follows from interpretation

### Major warning signs

* Proof-texting
* Isolated verses carrying unrelated claims
* Ignoring contradictory context
* Treating descriptive passages as commands
* Treating commands as universal promises
* Treating poetic language as literal proposition
* Treating narrative details as moral commands without justification
* Building the sermon around a popular interpretation unsupported by the text

If the central sermon claim cannot survive contextual examination of the primary text, the sermon requires substantial revision.

---

# 5. Interpretive Integrity

The evaluator should distinguish:

**What the text says**

from

**What the preacher wants the text to say.**

Evaluate whether the sermon:

* Respects genre
* Respects literary context
* Respects historical context
* Represents the author's argument
* Handles ambiguity honestly
* Distinguishes interpretation from application
* Avoids overclaiming
* Avoids false certainty

If legitimate scholarly disagreement exists, the sermon should not present a contested interpretation as unquestionably established unless there is sufficient justification.

---

# 6. Theological Coherence

The sermon should fit coherently within the theological framework defined by `theology.md`.

Evaluate:

* Doctrine of God
* Doctrine of Scripture
* Doctrine of humanity
* Sin
* Grace
* Salvation
* Christ
* Holy Spirit
* Church
* Kingdom
* Resurrection
* Final hope

Only relevant categories need to be evaluated.

The evaluator should look especially for accidental theological implications.

For example, a sermon may verbally affirm grace while structurally communicating:

> God accepts you if you perform well enough.

The evaluation should identify such contradictions.

---

# 7. Central Idea

The sermon should have one dominant idea.

Evaluate whether:

* The central idea is identifiable
* It is biblically grounded
* It is specific
* It is carried throughout the sermon
* Major sections contribute to it
* The conclusion returns to it
* Applications flow from it

### Central idea failure

A sermon is structurally weak when it effectively becomes:

```text
Interesting observation
+
Another interesting observation
+
Another Bible verse
+
Story
+
Advice
+
Conclusion
```

without a unifying claim.

---

# 8. Sermon Structure

Evaluate whether the structure creates meaningful movement.

Ask:

* Does the sermon have a beginning, development, and destination?
* Does each major movement have a purpose?
* Are transitions logical?
* Does the sermon build rather than merely accumulate?
* Does the conclusion resolve the sermon's central tension?
* Are there unnecessary sections?
* Is the structure appropriate to the biblical genre?

The evaluator should not penalize a sermon simply because it does not use three points.

Structure should serve the sermon rather than conform to a formula.

---

# 9. Exposition

Evaluate whether the sermon actually explains the biblical text.

A sermon should answer:

> What does this passage mean, and how do we know?

Evaluate:

* Explanation of important verses
* Context
* Logical reasoning
* Treatment of significant terms
* Connection between textual observations and conclusions
* Appropriate use of cross-references
* Distinction between explanation and speculation

### Exposition failure

A sermon that reads a passage and then spends most of its time discussing unrelated life advice has not necessarily preached the passage.

---

# 10. Theological Depth

Depth should not be measured by complexity.

Evaluate whether the sermon:

* Identifies meaningful theological implications
* Explains why the truth matters
* Connects individual observations to larger biblical themes
* Avoids shallow conclusions
* Avoids unnecessary theological complexity

The evaluator should prefer:

> **Simple truth understood deeply**

over:

> **Complex language that creates the appearance of depth.**

---

# 11. Application

Evaluate whether application is:

* Grounded in the sermon
* Specific
* Realistic
* Appropriate to the text
* Appropriate to the audience
* Theologically sound
* More than generic encouragement

The evaluator should identify applications that:

* Exceed the text
* Reduce grace to performance
* Create unnecessary guilt
* Turn descriptive biblical examples into universal commands
* Depend on assumptions not established by the sermon

Good application should answer:

> **What should change because this is true?**

---

# 12. Gospel and Redemptive Context

For Christian sermons, evaluate whether the sermon appropriately understands the passage within the larger biblical story.

Consider:

* Christ
* Cross
* Resurrection
* Grace
* Faith
* Kingdom
* New covenant
* New creation

Not every sermon requires the same emphasis.

The evaluator should reject two opposite errors:

### Error 1 — Gospel omission

The sermon treats Christian obedience as though salvation depends on human performance.

### Error 2 — Gospel insertion

The sermon attaches an artificial "Jesus died for you" conclusion that has no meaningful relationship to the text.

The question is:

> **Does the sermon understand this passage as part of the biblical story that culminates in Christ?**

---

# 13. Pastoral Integrity

The sermon should treat listeners as people rather than rhetorical targets.

Evaluate whether the sermon:

* Shows appropriate compassion
* Avoids manipulation
* Avoids unnecessary shame
* Avoids simplistic answers to complex suffering
* Avoids assuming everyone has the same circumstances
* Offers hope where hope is warranted
* Gives correction without contempt
* Gives encouragement without dishonesty

The sermon should tell the truth even when the truth is difficult.

It should also communicate difficult truth with appropriate pastoral wisdom.

---

# 14. Emotional Integrity

Emotional impact is not inherently evidence of quality.

Evaluate whether emotional moments are earned by the truth of the sermon.

Healthy emotional movement may include:

* Conviction
* Grief
* Wonder
* Joy
* Hope
* Gratitude
* Fear of God
* Repentance
* Courage
* Comfort

Warning signs include:

* Manufactured sentiment
* Repeated emotional escalation
* Manipulative music or storytelling assumptions
* Unrelated tragedies used merely to create emotion
* Emotional conclusions unsupported by the sermon
* Guilt used as a substitute for theological reasoning

The question is:

> **Would the emotional response still make sense if the rhetoric were stripped away?**

---

# 15. Clarity

Evaluate whether a listener can understand the sermon while hearing it once.

Consider:

* Sentence complexity
* Unnecessary jargon
* Repetition
* Transitions
* Definitions
* Explanations
* Abstract language
* Unclear references
* Long digressions

Clarity does not mean simplicity at all costs.

Complex theological ideas should be made understandable rather than removed.

---

# 16. Spoken Communication

A sermon is meant to be heard.

Evaluate whether the manuscript:

* Sounds natural when spoken
* Uses manageable sentence lengths
* Provides verbal signposts where needed
* Allows important ideas to breathe
* Avoids essay-like density
* Uses repetition intentionally
* Has natural conversational rhythm

A sentence that reads beautifully but is difficult to understand when spoken should be revised.

---

# 17. Rhetorical Effectiveness

Only after the preceding dimensions are sound should rhetorical effectiveness be evaluated.

Consider:

* Opening
* Transitions
* Stories
* Analogies
* Repetition
* Memorable phrases
* Contrast
* Questions
* Pacing
* Conclusion

Rhetorical devices should clarify and reinforce the message.

They should not become the message.

---

# 18. Illustrations

Each illustration should be evaluated for:

* Relevance
* Accuracy
* Clarity
* Emotional appropriateness
* Length
* Function
* Theological usefulness

Ask:

> Does this illustration make the truth clearer, more concrete, more memorable, or more emotionally understandable?

If not, it should probably be removed.

The evaluator should also flag illustrations that:

* Distract from the text
* Become more memorable than the theological point
* Contain questionable factual claims
* Create emotional manipulation
* Require excessive explanation

---

# 19. Research Quality

Evaluate research only where research is actually used.

Check:

* Accuracy
* Relevance
* Source quality
* Appropriate confidence
* Historical context
* Original-language claims
* Scientific claims
* Contemporary cultural claims

The agent should flag:

* Unsupported factual claims
* Weak sources
* Misrepresented scholarship
* Claims presented as fact when uncertain
* Unnecessary research included merely to sound authoritative

More research does not automatically produce a better sermon.

---

# 20. Economy

The evaluator should actively search for unnecessary material.

Ask of every major section:

> If this were removed, would the sermon become weaker?

If not, consider removing it.

Potential material for removal:

* Repeated explanations
* Redundant illustrations
* Interesting but irrelevant facts
* Excessive historical background
* Tangential theological observations
* Multiple applications saying essentially the same thing
* Unnecessary transitions
* Repeated conclusions

The goal is not the shortest sermon.

The goal is the **strongest sermon with nothing unnecessary.**

---

# 21. Conclusion Evaluation

The conclusion should be evaluated independently.

Ask:

* Does it return to the central idea?
* Does it resolve the opening tension?
* Does it provide an appropriate response?
* Does it avoid introducing major new ideas?
* Does it end with theological substance rather than emotional manipulation?
* Does it leave the listener with the sermon's intended landing point?

A sermon should not simply fade out.

It should arrive somewhere.

---

# 22. Evaluation Severity

Every identified issue should receive a severity level.

### CRITICAL

The problem compromises biblical or theological integrity.

Examples:

* Major misinterpretation of the primary text
* Doctrinally false claim
* Scripture used to support a claim it does not make
* Central application contradicts the text

**Action: Must revise before proceeding.**

### MAJOR

The sermon remains potentially usable but has a significant weakness.

Examples:

* Central idea is unclear
* Structure does not develop
* Important context is missing
* Application substantially exceeds the text
* Major section is disconnected from the sermon

**Action: Strongly recommend revision.**

### MODERATE

The sermon is sound but could be materially improved.

Examples:

* Weak transition
* Overlong explanation
* Generic application
* Redundant illustration
* Underdeveloped theological implication

**Action: Revise if time and purpose warrant.**

### MINOR

A localized improvement.

Examples:

* Awkward sentence
* Small redundancy
* Slightly unclear phrasing
* Minor stylistic issue

**Action: Optional refinement.**

---

# 23. Evaluation Scores

The agent may use scores as an internal diagnostic, but scores must never replace explanation.

Suggested dimensions:

```text
Scriptural Faithfulness      /10
Interpretive Integrity       /10
Theological Coherence        /10
Central Idea                 /10
Structure                    /10
Exposition                   /10
Application                  /10
Gospel / Redemptive Context  /10
Pastoral Integrity           /10
Clarity                      /10
Emotional Integrity          /10
Rhetorical Effectiveness     /10
```

Scores should be accompanied by evidence.

A numerical score without explanation is not a useful evaluation.

---

# 24. Evaluation Output

When evaluating a sermon, the agent should normally produce:

```text
Overall Assessment

Primary Strengths
- ...
- ...
- ...

Critical Issues
- ...
- ...

Major Improvements
- ...
- ...

Minor Refinements
- ...
- ...

Recommended Revision Priority
1. ...
2. ...
3. ...

Final Assessment
...
```

If no critical or major problems exist, the agent should say so.

The evaluator should not manufacture criticism simply to appear thorough.

---

# 25. Revision Priority

When multiple problems exist, revisions should be prioritized according to:

1. Scriptural faithfulness
2. Interpretive integrity
3. Theological coherence
4. Central idea
5. Structural integrity
6. Exposition
7. Application
8. Pastoral integrity
9. Clarity
10. Rhetorical polish

The agent should not spend time polishing sentences while foundational problems remain unresolved.

---

# 26. Evaluation Independence

The evaluator should not assume the sermon is good simply because the development process produced it.

It should independently test the final product.

Likewise, it should not assume the sermon is bad simply because it differs from a common sermon pattern.

Evaluation should be evidence-based.

---

# 27. Avoiding Stylistic Bias

The evaluator must distinguish between:

**"I would write this differently."**

and:

**"This does not work."**

The following are not inherently flaws:

* Long or short sermons
* Narrative structures
* Topical structures
* Expository structures
* Conversational language
* Formal language
* Emotional sermons
* Analytical sermons
* Three-point outlines
* No-point outlines

Style should only be criticized when it interferes with the sermon’s purpose, clarity, faithfulness, or pastoral integrity.

---

# 28. Final Evaluation Gate

A sermon should not be considered final if any of the following remain unresolved:

* Critical biblical error
* Critical theological error
* Fundamental misinterpretation of the primary text
* Unclear central idea
* Broken sermon movement
* Application that materially contradicts the text
* Serious factual claims that remain unsupported
* Manipulative emotional conclusion

A sermon may still contain imperfections and be considered final.

The goal is not perfection.

The goal is **faithful, coherent, pastorally responsible proclamation.**

---

# 29. Core Rule

The evaluator should always ask:

> **Is this sermon faithful to Scripture, clear about what Scripture means, honest about what it cannot establish, theologically coherent, pastorally responsible, and purposeful in its call to respond?**

If the answer is no, the agent should identify why.

If the answer is yes, the agent should resist unnecessary revision merely for the sake of improvement.

**Evaluation exists to make the sermon more faithful and more useful—not merely more polished.**
