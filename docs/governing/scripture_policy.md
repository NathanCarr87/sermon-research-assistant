# Scripture Policy

## 1. Purpose

This document governs how Sermon Creator discovers, evaluates, interprets, references, and uses Scripture.

Scripture is a unique source within the Sermon Creator system.

It must not be treated as merely another item in the research database.

The purpose of this policy is to ensure that Scripture is:

- accurately represented
- interpreted responsibly
- presented in context
- appropriately translated
- distinguished from commentary
- distinguished from theological tradition
- faithfully connected to sermon application

---

## 2. Scripture as Primary Text

The biblical text is the primary source for biblical claims.

Commentaries, theological works, sermons, websites, study guides, and other sources may assist interpretation but must never be presented as though they are Scripture.

The system must maintain a strict distinction between:

SCRIPTURE
→ what the biblical text says

INTERPRETATION
→ what the text means

THEOLOGY
→ conclusions drawn from Scripture and theological reasoning

APPLICATION
→ how the biblical truth may be lived out today

---

## 3. Canon

The system must operate according to the biblical canon specified by the configured theological profile.

The agent must not silently assume a canon when the user's theological tradition is ambiguous.

If different Christian traditions recognize different canonical collections, the distinction should be preserved when relevant.

---

## 4. Translation

The theological profile should specify a preferred Bible translation.

When no translation is specified, the agent should use an appropriate mainstream translation and record which translation was used.

The agent must not:

- combine translations without identifying them
- alter wording while presenting it as a quotation
- create a pseudo-translation
- paraphrase while labeling the result as a direct quotation

---

## 5. Scripture Quotations

Scripture quotations must accurately correspond to the identified translation.

When quoting Scripture:

- identify the translation when appropriate
- preserve the wording accurately
- preserve the relevant passage boundaries
- do not modify wording to make the verse fit the sermon

If the exact wording cannot be verified, paraphrase it and clearly identify it as a paraphrase.

---

## 6. Reference Accuracy

Every Scripture reference must be valid.

The system must verify:

- book
- chapter
- verse
- verse range
- translation when relevant

Never generate a Scripture reference based solely on memory when verification is available.

The system must not fabricate references.

---

## 7. Primary Text Selection

Every sermon should have a clearly identified primary text unless the sermon format intentionally calls for a topical or thematic structure.

When selecting a primary text, consider:

- relevance to the sermon question
- sufficient contextual scope
- literary unit
- genre
- theological significance
- ability to support the sermon objective

The agent should prefer meaningful passages over isolated proof-texts.

---

## 8. Passage Boundaries

The agent should determine the appropriate literary unit before interpreting a passage.

Do not automatically interpret a single verse independently when:

- the surrounding paragraph changes its meaning
- the surrounding argument is essential
- the verse is part of a larger narrative
- the verse depends upon preceding or following verses

The appropriate unit may be:

- a verse
- several verses
- a paragraph
- a narrative episode
- a chapter
- a larger literary section

The sermon does not need to quote the entire unit, but the interpretation should account for it.

---

## 9. Context

Scriptural interpretation should consider context at multiple levels.

### Immediate Context

What comes immediately before and after the passage?

### Literary Context

What role does the passage play within the book?

### Historical Context

What circumstances surrounded the original audience?

### Cultural Context

What cultural assumptions or practices affect interpretation?

### Canonical Context

How does the passage relate to the broader biblical narrative?

### Theological Context

How has the passage been understood within the configured theological tradition?

The level of contextual analysis should be proportional to the importance and complexity of the passage.

---

## 10. Genre

The agent must identify the genre of the passage before making interpretive claims.

Relevant genres include:

- narrative
- poetry
- wisdom
- prophecy
- apocalyptic
- Gospel
- epistle
- law
- historical narrative
- parable
- wisdom saying
- genealogical material

Genre affects interpretation.

The agent must not treat:

- poetry as ordinary prose
- narrative description as automatic prescription
- metaphor as literal description
- apocalyptic imagery as ordinary historical prose
- wisdom principles as unconditional promises

---

## 11. Interpretation

The agent should seek the most defensible interpretation based on:

- textual evidence
- context
- genre
- language
- historical setting
- canonical context
- established scholarship
- configured theological tradition

The agent should not select an interpretation simply because it produces a better sermon.

The sermon must serve the text rather than the text serving the sermon.

---

## 12. Original Languages

Hebrew, Aramaic, and Greek analysis may be used when it materially improves interpretation.

The agent should consider:

- significant vocabulary
- semantic range
- grammar
- syntax
- textual variants
- translation differences

Original-language analysis must not be used merely to create the appearance of scholarly authority.

Avoid claims such as:

"The Greek word literally means..."

when the actual semantic range is broader.

A word's meaning is determined by context, not merely by its dictionary entry.

---

## 13. Translation Differences

When translations differ in a way that materially affects interpretation, the agent should identify the difference.

For example:

- significant lexical differences
- meaningful grammatical differences
- textual-variant differences
- major interpretive choices

Minor stylistic differences do not require discussion.

---

## 14. Textual Variants

Where significant textual variants exist, the agent should acknowledge them when they materially affect the sermon.

The agent should distinguish:

- the existence of a textual variant
- the likely original reading
- translation decisions
- theological implications

The presence of a textual variant does not automatically invalidate the passage.

Do not conceal significant textual issues merely because they complicate the sermon.

---

## 15. Cross-References

Cross-references must have a defensible relationship to the primary text.

They may serve as:

- theological clarification
- thematic connection
- canonical development
- supporting evidence
- contrast
- fulfillment
- parallel teaching

The agent should avoid accumulating large numbers of loosely related verses.

A small number of meaningful cross-references is preferable to verse dumping.

---

## 16. Old and New Testament Relationships

When connecting Old and New Testament passages, the agent must distinguish among:

- direct quotation
- allusion
- thematic relationship
- typology
- prophecy
- fulfillment
- theological development

The agent must not automatically claim that every thematic similarity represents a direct prophetic prediction or fulfillment.

---

## 17. Narrative Interpretation

Narrative passages should distinguish between:

WHAT THE TEXT REPORTS

and

WHAT THE TEXT COMMANDS

The fact that a biblical character did something does not automatically mean Scripture endorses that behavior.

When interpreting narrative, consider:

- narrator perspective
- character motivations
- consequences
- repeated themes
- explicit commentary by the biblical author
- larger narrative arc

---

## 18. Parables

Parables should be interpreted according to their literary function.

The agent should avoid:

- assigning arbitrary symbolic meaning to every detail
- treating every character or object as a coded theological symbol
- importing unrelated doctrines into individual details

Focus primarily on the central point or points supported by the text.

---

## 19. Poetry and Metaphor

Poetic language should be interpreted according to its literary form.

The agent should recognize:

- metaphor
- hyperbole
- parallelism
- personification
- imagery
- poetic repetition

Do not construct literal doctrinal claims from poetic imagery without appropriate justification.

---

## 20. Prophecy and Apocalyptic Literature

Prophetic and apocalyptic passages require particular care.

The agent should consider:

- historical setting
- symbolism
- genre
- original audience
- competing interpretive frameworks
- relevant canonical connections

The agent must not present speculative end-times interpretations as settled biblical fact.

When significant interpretive disagreement exists, the theological profile should determine the preferred framework.

---

## 21. Epistles

Epistolary passages should be interpreted as arguments rather than isolated collections of statements.

Consider:

- author's argument
- audience
- rhetorical purpose
- preceding claims
- following conclusions
- cultural context

A single sentence should not be interpreted independently when the surrounding argument materially affects its meaning.

---

## 22. Topical Sermons

A topical sermon must still be biblically grounded.

The agent should:

1. define the topic
2. identify relevant biblical teaching
3. select representative passages
4. interpret those passages in context
5. synthesize the biblical teaching
6. distinguish synthesis from individual textual claims
7. develop application

The agent must not search for verses containing a desired keyword and treat those verses as proof of a predetermined conclusion.

---

## 23. Proof-Texting

Proof-texting should be avoided.

A passage should not be used merely because it contains words related to the sermon topic.

Before using a passage as support, ask:

> "Would this passage still support this claim if we read the surrounding context?"

If not, the passage should be reconsidered.

---

## 24. Difficult Passages

When Scripture contains difficult, ambiguous, or apparently contradictory passages, the agent should not hide the difficulty.

It should:

- identify the interpretive issue
- examine context
- consult reputable scholarship
- identify major interpretations when necessary
- follow the configured theological profile
- avoid false certainty

Difficulty should be handled honestly without unnecessarily derailing the sermon.

---

## 25. Apparent Contradictions

When two passages appear to conflict, the agent should not immediately force a simplistic harmonization.

First examine:

- context
- genre
- audience
- terminology
- chronology
- authorial purpose
- translation
- textual variants

If credible interpretive disagreement remains, preserve the uncertainty where appropriate.

---

## 26. Scripture and Science

When Scripture intersects with scientific questions, the agent must distinguish:

- what Scripture explicitly teaches
- theological interpretation
- historical interpretation
- scientific evidence
- philosophical assumptions

The agent must not claim that Scripture directly answers a scientific question unless the text actually addresses it.

Likewise, scientific claims must not be presented as though they automatically settle theological questions.

---

## 27. Scripture and Current Events

Current events should illuminate Scripture, not redefine it.

The system may connect contemporary events to biblical themes when the connection is legitimate.

The agent must not:

- claim a current event is biblical prophecy without adequate basis
- declare divine causation without appropriate theological justification
- force every major event into a biblical narrative
- use Scripture as a partisan commentary device

---

## 28. Scripture and Personal Experience

Personal experience may illustrate biblical truth.

Personal experience does not establish biblical doctrine.

The agent should distinguish:

"Someone experienced X."

from:

"Therefore Scripture teaches X."

Testimony may be meaningful without becoming theological proof.

---

## 29. Scripture and Theology

When a theological doctrine is derived from multiple passages, identify it internally as theological synthesis.

Do not attribute the entire doctrine to a single verse when the doctrine actually depends upon broader biblical reasoning.

The sermon may present a coherent theological conclusion while maintaining accurate attribution.

---

## 30. Scripture and Tradition

Historical or denominational interpretations may be referenced.

They must remain distinguishable from Scripture.

Use language appropriate to the evidence:

"Scripture teaches..."

"The early church commonly understood..."

"The Reformed tradition interprets..."

"Many Pentecostal theologians understand..."

"One scholarly interpretation argues..."

Never collapse these categories.

---

## 31. Scripture Selection for Application

Application should arise naturally from the text.

The agent should ask:

- What does this passage reveal?
- What does it call people to believe?
- What does it call people to do?
- What does it challenge?
- What does it promise?
- What does it warn against?
- How does this apply to the congregation?

Application should not be added merely to satisfy a sermon template.

---

## 32. Scripture Reference Classification

Every Scripture reference in the Sermon Package should be classified as one of:

```text
PRIMARY
The principal passage upon which the sermon is built.

SUPPORTING
A passage that directly supports or clarifies the sermon argument.

CROSS_REFERENCE
A related passage that illuminates the theme.

ILLUSTRATIVE
A passage used primarily to provide an example or additional perspective.
The classification should be meaningful rather than decorative.

33. Scripture Evidence Record

Each important Scripture passage should maintain an internal record containing:

reference
translation
passage role
context
genre
interpretive summary
relevant theological considerations
supporting sources
interpretive confidence
disputed interpretations when relevant

This information supports the sermon architect and theological auditor.

34. Biblical Claim Traceability

Every significant biblical claim should be traceable.

The desired chain is:

SERMON CLAIM
→ BIBLICAL CLAIM
→ SCRIPTURE REFERENCE
→ INTERPRETATION
→ CONTEXT / SUPPORTING RESEARCH

A reviewer should be able to determine:

"Why does the sermon say this?"

and trace the answer back to the biblical text.

35. Scripture Audit

Before a sermon passes biblical review, verify:

Reference Accuracy

Are all references valid?

Quotation Accuracy

Are quoted passages accurately represented?

Translation Accuracy

Is the stated translation correct?

Context

Has the passage been interpreted in context?

Genre

Has the literary genre been considered?

Interpretation

Does the sermon reasonably represent the passage?

Cross-References

Do supporting passages actually support the claim?

Application

Does application follow legitimately from interpretation?

Doctrinal Claims

Are theological conclusions appropriately distinguished from explicit textual statements?

Uncertainty

Have legitimate interpretive disagreements been represented honestly?

36. Final Scripture Standard

The final sermon should be able to answer:

"Where does this come from?"

with a defensible answer.

When the answer is Scripture, the text must actually support the claim.

When the answer is theological interpretation, it must be identified as such.

When the answer is application, it must not be disguised as biblical quotation or explicit biblical command.

The governing principle is:

Do not make Scripture say more, less, or something different than it actually says.
